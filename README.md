# 松针雪夜 · 垒树挑战

原创圣诞主题网页小游戏，无外部资源、账号或后台。打开 `index.html` 或在项目目录用静态服务器托管。

- ←／→ 或 A／D 移动雪橇；手机可横拖游戏场地，也可按住左右箭头。Esc 暂停。
- 平台只接第一片。往后用**整棵树最上面那层**接叶；落下的叶片保留与树顶的真实偏移量。
- 重叠太少就漏接。普通、靠中、精准分别 +10／20／30；越悬边，树越晃，精准落点能减晃。连续四次精准还会补回一颗心，并触发彩灯雨。
- 漏接 −10 分、失一颗心。五颗心耗尽或树太晃就结束。彩灯 +30 且减晃。
- 第 12 层亮起星星但不会停止。随高度上升，叶片逐渐变窄至保底宽度，增加风力和下落速度；镜头会跟着树顶上移。
- 本机最高层数和最高分分别保存在浏览器，不上传数据。

`node --test tests/*.test.js` 检查几何、垒层、倒塌、最高层纪录及模拟交互。
